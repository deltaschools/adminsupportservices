System Principle

Weekly PI = one complete PI per grade containing all applicable subjects.
Daily Learning Report = actual timetable-period reporting for each grade and section.

Weekly Performance Indicator

The complete weekly PI for the selected grade will appear here. All applicable subjects will be visible. Teachers will be able to edit only the subject(s) assigned to them.

Example:
Grade 1 → Week 1 → Whole PI

English — editable for assigned English teacher
Mathematics — view only for other teachers
Science — view only for other teachers
Arabic — view only for other teachers

HOD / Academic Supervisor Review

Only the assigned HOD / Academic Supervisor approves or returns academic records.

Principal: View only within assigned scope.
General Academic Manager: View all only.
Report Personnel: Access finalized PDFs and download.

Timetable Management

Timetable scopes, grade ranges, break structures, weekly period totals, and effective weeks will all be configurable.

A timetable may cover KG1–KG3, Grade 1–3, Grade 1–6, or any future combination. Nothing is hard-coded.

PDF Reports

Approved PI and Daily Learning Report PDFs will be generated automatically and stored in the school's Google Drive.

History & Versions

Approved versions will never be silently overwritten. V1, V2, V3 and historical PDFs will remain traceable.

System Administration

Authorized administrators will manage employees, assignments, permissions, subjects by grade, academic calendar, timetable versions, and system settings.

مبدأ النظام

مؤشر الأداء الأسبوعي = مؤشر كامل لكل صف ويشمل جميع المواد المطبقة.
التقرير اليومي للتعلم = تقرير حسب الحصة الفعلية في جدول كل صف وشعبة.

مؤشر الأداء الأسبوعي

سيظهر هنا مؤشر الأداء الأسبوعي الكامل للصف المحدد. ستظهر جميع المواد المطبقة، بينما يقتصر التحرير على المواد المكلّف بها المعلم.

متابعة مؤشرات الأداء

ستعرض لوحة المتابعة عدد المواد التي تحتاج إلى إجراء وأسماء تلك المواد بالتحديد.

التقرير اليومي للتعلم

يتبع تقرير أولياء الأمور ترتيب الحصص الفعلي في جدول الشعبة لذلك اليوم.

الحصة المادة معلم/ـة المادة ما تعلمناه اليوم مهمة الأداء التدريب لإتقان المهارة
ستظهر هنا إدخالات اليوم المبنية على الجدول.

متابعة التقارير اليومية

سيحدد النظام الشعبة أو الحصة أو المادة أو إدخال التدريب لإتقان المهارة الذي لا يزال غير مكتمل.

مراجعة رئيس القسم / المشرف الأكاديمي

رئيس القسم / المشرف الأكاديمي المكلّف هو الجهة الوحيدة التي تعتمد أو تعيد السجلات الأكاديمية للتعديل.

إدارة الجداول

ستكون نطاقات الجداول والصفوف وفترات الاستراحة وعدد الحصص الأسبوعية وأسبوع السريان جميعها قابلة للإعداد.

تقارير PDF

سيتم إنشاء ملفات PDF المعتمدة لمؤشرات الأداء والتقارير اليومية تلقائيًا وحفظها في Google Drive الخاص بالمدرسة.

السجل والإصدارات

لن يتم استبدال الإصدارات المعتمدة بصمت، وستظل الإصدارات السابقة قابلة للتتبع.

إدارة النظام

سيتمكن مسؤولو النظام المخولون من إدارة الموظفين والتكليفات والصلاحيات والمواد حسب الصف والتقويم الأكاديمي وإصدارات الجداول وإعدادات النظام.
